Simulated Multi-Currency Digital Payments Platform

VYOM delivers bank-grade double-entry transaction processing, pessimistic row-locking concurrency control, and per-account idempotency. Engineered for deterministic financial integrity.

Double-Entry Ledger PostgreSQL Row Locks Zero-Loss Idempotency Exact 4-Decimal Precision Auditable Receipts
Simulation Environment Notice: VYOM is a simulated financial platform for demonstrating transaction processing architecture. All wallets, balances, and funding operations use test data only. No real banking, UPI, or external card payment systems are accessed.

Strict Double-Entry Bookkeeping

Every funding, transfer, refund, and reversal writes balanced debit and credit entries to an immutable append-only ledger. Global financial invariants are verified on every transaction.

Deterministic Concurrency Control

Multi-wallet operations acquire row-level locks in deterministic ascending UUID order, eliminating deadlocks under extreme high-concurrency workloads.

Per-User Idempotency Protection

Every mutating request requires a unique idempotency key. Network retries return identical cached responses without accidental duplicate debits or double spends.

Lifecycle & Administrative Oversight

Comprehensive transaction tracking with dispute filings, customer-initiated refunds, and role-enforced administrative reversals protected by Spring Security RBAC.
